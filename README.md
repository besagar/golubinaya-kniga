# Голубиная книга

HTML-презентация к докладу о русском духовном стихе «Голубиная книга».

- **[index.html](https://besagar.github.io/golubinaya-kniga/)** — основная версия, 16 слайдов
- [v1.html](https://besagar.github.io/golubinaya-kniga/v1.html) — ранняя длинная редакция
- [v2.html](https://besagar.github.io/golubinaya-kniga/v2.html) — сокращённая редакция, 14 слайдов

Управление: `→` / `←` — листать (на слайдах с вопросами первое нажатие раскрывает ответ),
`↓` / `↑` — перейти через слайд целиком, `F` — полный экран, `N` — заметки докладчика.

## Источники

Тексты стиха цитируются по изданиям XIX — начала XX в.: сборник Кирши Данилова,
А. В. Оксенов «Народная поэзия» (СПб., 1908), «Животная книга духоборцев»
под ред. В. Д. Бонч-Бруевича (СПб., 1909). Научный аппарат — Веселовский,
Мочульский, Федотов, Топоров, Никитина, Кузнецова; полный список на последнем слайде.

Иллюстрации: Н. К. Рерих, «Голубиная книга» (1911, 1922); фотография И. А. Федосовой.
